**Project Owner** &middot; AGV-level multi-sensor fusion module for static and dynamic obstacle state estimation.

1. Built the fusion pipeline that combined heterogeneous on-board sensors to estimate the position, velocity, and class of surrounding obstacles in real time.
2. Tuned for AGV (Automated Guided Vehicle) operating environments where both static map obstacles and dynamic agents need consistent tracking.
