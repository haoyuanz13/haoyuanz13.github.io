**Project Owner** &middot; Camera-based semantic mapping for parking environments using line and marker features.

1. Designed the semantic-mapping algorithm that lifts in-camera line and marker features into a persistent parking-lot map.
2. Used the resulting map for lane- and slot-level localization in valet/AVP-style scenarios.
